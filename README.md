# AI Car Ad Generator — n8n + Telegram

## Overview
A personal automation project built with n8n that uses AI-assisted text generation and Telegram messaging to create vehicle advertisement content.

## Features
- n8n workflow automation
- AI-assisted car advertisement generation
- Telegram messaging integration
- Structured vehicle information and generated ad content

## Current Status
This project is an early-stage personal prototype. Vehicle details are currently entered directly into the n8n workflow. The workflow sends the generated content through Telegram.

## Planned Improvements
- Accept vehicle details dynamically through Telegram
- Support different languages and international markets
- Add input validation and error handling
- Improve testing and setup documentation

## Requirements
- An n8n instance
- A Telegram bot
- An AI model provider and its required credentials

## Setup
Import the sanitized workflow JSON into n8n. Configure your own Telegram and AI credentials, review the workflow settings, and test it with sample vehicle information before use.

## Security
Never share API keys, bot tokens, passwords, or private customer information in this repository.

## Disclaimer
This is a personal learning and portfolio project. It is a prototype and is not presented as a production-ready service.
